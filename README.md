# Machine Learning Lab

Exploring **Machine Learning and Deep Learning from first principles** through mathematics, implementations, experiments, and visualizations.

## Objectives
- Understand the mathematics behind ML algorithms.
- Implement algorithms from scratch using Python and NumPy.
- Experiment with models and visualize their behaviour.
- Develop practical skills in Machine Learning and Deep Learning.

## Tools & Technologies
Python · NumPy · Pandas · Matplotlib · Scikit-learn · PyTorch

## Projects
- **Linear Models** — Linear Regression, loss functions, regularization, and optimization.
- More algorithms and experiments will be added as I progress.

## Learning Philosophy

**Understand → Implement → Experiment → Visualize → Explore**

Learning by building, one model at a time.
